# Application answer

https://github.com/AlBaraa-Mahmoud/signal-form-motion-study

SIGNAL / FORM is a code-driven motion-design study built with AI assistance on the code. It renders a 12-second HTML5 Canvas sequence combining masked kinetic typography, a procedural orbital line field, and data-driven bars with synchronized numeric counters. Configurable parameters include scene timing, frame rate, output resolution, typography, copy, colors and the dataset driving the chart. A deterministic, frame-indexed drawing function powers both browser playback and offline rendering. The export script renders PNG frames with @napi-rs/canvas and pipes them to FFmpeg to create a silent H.264 MP4. The included sample is 1280 × 720 at 30 fps, verified as 360 frames over 12 seconds. The repository includes editable source, playback controls, automated checks, a README and the sample render.
